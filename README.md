# Reid's guessing games

Play-along versions of the guessing games from Reid's YouTube videos.
Static site, served by GitHub Pages. No build step.

## Add a game
1. Copy the video's slideshow into `<slug>/index.html` (+ its `img/`), set `REID` (his on-camera
   guesses) and `VIDEO_URL` at the top of the script.
2. Add a line to `GAMES` in `index.html` (newest first).
3. Commit and push — Pages updates in about a minute.
